# Презентации HRlink

`src/app/(presentations)/layout.tsx` — отдельный корневой layout App Router.
Он подключает локальный Onest, светлую фирменную палитру и метаданные.
Тема, язык и CSS личного сайта живут в `(site)` и не влияют на презентации.

Источник правил оформления: `Brandbook_source/Brandbook_HRlink_Final.pdf`,
страницы 20–28. Эталон сетки и размеров — `Презентация HRlink.pptx`
из `Master_files/3_Presentation` (16:9). При расхождении приоритет у финального
брендбука: например, линия шапки не заходит в охранное поле логотипа.
Onest взят из комплекта брендбука; пробный Rooftop Mono не включён.
Контакты используют разрешённый брендбуком системный Arial.
Исходный `Master_files/0_Logo/svg/Logo_blue.svg` скопирован без изменений
в `public/presentations/hrlink/brand/logo.svg`; его внутренние поля сохранены.
Заголовки — 52 px, обложка — 64 px на холсте 1920×1080.
На каждом слайде есть фирменный оранжевый акцент; QR используют тёмно-синий.
Бейдж на заключительном слайде повторяет светлый пропуск со страницы 11
`HRlink_identity_concept_21.07.2026.pdf`. `brand/badge-reference.jpg` извлечён
из этой страницы без изменений. SVG показывает исходную карточку и крепление;
логотип, линия, `Employee Experience Platform` и `hr-link.ru` сохраняются
в оригинальном изображении, вместе с их шрифтами и расположением.
Имена и должность заменены на персональные данные Сергея: Onest Regular,
34 px и 20 px в системе координат референса; регистр и отступы сохранены.
Портрет — исходный `sergey-badge-photo.png`, без генеративной обработки.
CSS показывает квадратный кадр 190×190 от точки (475, 135) изображения
853×1280 внутри круглой маски, сохраняя монохромное оформление референса.

## Общие макеты

- `SlideLayout`: `cover`, `content`, `section`, `closing`; номер задаёт стабильные
  `slide-NN` и `title-NN`, заголовок и подпись передаются отдельно от содержимого.
- `ComparisonLayout`: две смысловые колонки, на узком экране — одна.
- `ColumnsLayout`: колонки для этапов и результатов; композицию можно уточнить классом.
- `CardsLayout`: прямоугольные блоки по макету «Кто мы?».
- `PresentationHeader`: логотип, линия, подпись материала и номер слайда.
- `PresentationDetail`: единая оболочка пояснений и оглавления; сохраняет
  структуру для контроллера диалогов и чтения без JavaScript.
- `SlideTail`: нижняя строка с пояснениями и следующей темой.
- `ControlIcon` и `PresentationIcon`: повторяющиеся SVG-иконки.
- `SdlcQuestionsLink`: общая форма вопросов и QR-код для слайдов SDLC.
- `hrlink-sdlc/autonomy-levels.ts`: общий источник описаний для таблицы
  уровней и клиентского переключателя.

`brand.css` содержит общие правила типографики, макетов, пояснений и навигации.
CSS страницы SDLC содержит только композиции конкретного материала.
Презентация свёрстана в фиксированных px для холста 1920×1080 без медиазапросов
по ширине окна: `.deck` всегда занимает всю ширину окна в пропорции 16:9,
контроллер задаёт `--deck-scale` через `zoom`. Если окно ниже 16:9, страница
прокручивается; полный экран на мониторе 16:9 совпадает с холстом.

## Содержание SDLC

`hrlink-sdlc/slide-01.tsx` — `slide-19.tsx` являются серверными компонентами.
Изображения вынесены в `public/presentations/hrlink`, шрифт подключён через `next/font/local`.
`DeckEnhancer` добавляет навигацию, пояснения, полный экран, масштаб холста и вопросы к готовому DOM;
контроллер SDLC очищает подписки, запросы и интервалы при размонтировании.
Без JavaScript серверный HTML содержит все слайды и раскрываемые пояснения.

Публичный адрес сохранён: `/presentations/hrlink-sdlc/`, включая якоря `#slide-NN`.
`trailingSlash` создаёт `out/presentations/hrlink-sdlc/index.html`, поэтому старая
прямая ссылка на `index.html` также работает на статическом хостинге.
Не следует возвращать HTML-копию в `public`: она конфликтует с маршрутом Next.js.

Проверка: `npm run lint`, `npm run build`, затем настольный просмотр всех слайдов
на холсте 1920×1080 и в окне настольного браузера. Холст сохраняет пропорции 16:9.
Мобильные макеты и мобильные проверки презентациям не требуются (см. AGENTS.md).
Проверять оглавление, Escape, историю браузера, уровни 0–4 и загрузку вопросов.
